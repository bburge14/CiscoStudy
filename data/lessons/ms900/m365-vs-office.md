# Microsoft 365 vs. Office

People use the words "Office" and "Microsoft 365" as if they mean the same thing,
and the exam deliberately tests whether you know they don't. One is a one-time
purchase of desktop apps; the other is a cloud subscription that *includes* those
apps and a great deal more. Getting this distinction right unlocks a surprising
number of questions.

## Two very different ways to buy

There are two ways to get Word, Excel, PowerPoint, and friends:

> **Office** (the traditional, perpetual-license product) is bought **once** and
> installed on a device. **Microsoft 365** is a **subscription** that is always
> kept current and bundles the Office apps *together with* cloud services.

### Traditional Office — the one-time purchase

A perpetual (or "standalone") edition of Office — for example **Office 2021** or
**Office 2024** — is a classic software purchase:

- You **pay once** and own that version indefinitely.
- It installs on (typically) **one PC or Mac**.
- It receives **security patches** for a support period but **does not get new
  features** — the version you bought is the version you keep.
- It is **just the apps**. There are no bundled cloud services, so no business
  email hosting, no extra cloud storage, no Teams.
- To move to a newer version, you buy it again.

Think of it like buying a printed reference book: it's yours forever, but it never
updates. When a new edition comes out, you buy the new book.

### Microsoft 365 — the subscription

Microsoft 365 is sold as a recurring (monthly or annual) **subscription per user**.
It gives you much more than the apps:

- The **always-up-to-date Office desktop apps**, which gain new features
  continuously — no buying the next version.
- The right to install the apps on **multiple devices** per user (PCs, Macs,
  tablets, and phones).
- **Cloud services** such as **Exchange Online** (hosted business email and
  calendars), **OneDrive** (personal cloud storage), **SharePoint Online**, and
  **Microsoft Teams** — depending on the plan.
- **Real-time co-authoring**, where several people edit the same cloud-stored
  document at once.
- It stops working if the subscription lapses, because you're renting access, not
  owning a version.

Think of it like a streaming service: as long as you subscribe, you always have
the latest catalog.

## "Microsoft 365 Apps" — name the thing precisely

Within a subscription, the installed desktop client applications have a specific
name you should memorize.

> **Microsoft 365 Apps** is the official name for the **subscription version of the
> Office desktop client applications** (Word, Excel, PowerPoint, Outlook, and so
> on). It was previously called *Office 365 ProPlus*.

So "Office" is the broad family name for the productivity apps, while **Microsoft
365 Apps** is specifically the subscription-delivered, continuously-updated
desktop edition that comes with your plan. There is also **Office for the web** —
free, lightweight browser versions of Word, Excel, and PowerPoint that run with no
installation, useful on locked-down or shared devices.

## Side-by-side

| | Perpetual Office (e.g. Office 2021/2024) | Microsoft 365 subscription |
|---|---|---|
| **How you pay** | One-time purchase, own it | Recurring subscription per user |
| **New features** | No — only security fixes | Yes — continuously updated |
| **Devices per user** | Usually one | Multiple |
| **Cloud services** (email, OneDrive, Teams) | None | Included (plan-dependent) |
| **Real-time co-authoring** | Limited | Yes, built in |
| **Stops if you stop paying** | No | Yes |

## Which one should a scenario pick?

The exam phrases this as a business need. Watch for these tells:

- "We want the apps to **always be the latest version**" → Microsoft 365
  subscription.
- "Staff must install Office on **several of their own devices** and **edit the
  same documents together** with files saved in the cloud" → Microsoft 365
  subscription.
- "We bought Office **once** and only want **security updates**, installed on
  **individual PCs**" → a perpetual/standalone edition of Office.
- "Name the **subscription version of the Office desktop apps**" → Microsoft 365
  Apps.

The default modern answer, and the one Microsoft steers customers toward, is the
subscription — because always-current apps plus cloud services and collaboration
are exactly the things a one-time purchase can't provide.

## The whole thing in one paragraph

**Office** as a one-time purchase (Office 2021/2024) is bought once, installed on a
single device, receives only security fixes, and includes no cloud services.
**Microsoft 365** is a per-user subscription that keeps the Office apps
continuously updated, allows installation on multiple devices, and bundles cloud
services like Exchange Online, OneDrive, SharePoint, and Teams, with real-time
co-authoring — but it stops working if the subscription ends. The installed
subscription apps are specifically called **Microsoft 365 Apps** (formerly Office
365 ProPlus), and **Office for the web** provides free browser-based versions.

## Exam focus

- **Perpetual Office = buy once, no new features, apps only.** **Microsoft 365 =
  subscription, always current, apps + cloud services, multi-device.**
- The go-to answer for "always-current apps and the ability to collaborate with
  cloud-stored files on several devices" is a **Microsoft 365 subscription**.
- **Microsoft 365 Apps** is the precise name for the **subscription version of the
  Office desktop client apps** (was *Office 365 ProPlus*).
- **Office for the web** = free, browser-based, no install — good for shared or
  restricted devices.
- Remember the dependency: a subscription **stops working if you stop paying**;
  a perpetual license does not.
